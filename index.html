CyberGuard is a learning project that joins C++, Python, Oracle and web pages in one application.

It is an educational toolkit. It is not a penetration-testing tool, a malware scanner or a certified security product, and a green result here does not mean a system is safe.

The page you see is HTML, CSS and JavaScript. A C++ server does the main calculations, Python handles passwords, logs and IP addresses, and Oracle stores the history.
